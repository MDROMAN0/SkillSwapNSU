The exchange

Four steps, no payment

Every exchange follows the same path, which is why the request status is a single column in the database with five possible values: Pending, Accepted, Rejected, Cancelled and Completed.

Browse students
1

List your skills

Mark each skill as something you can teach or something you want to learn, and set your level from Beginner to Expert.

2

Send a request

Filter by skill, department or level, then offer a trade. Your partner sees exactly what each side gives and gets.

3

Book the session

Pick a date, time and duration. Online sessions carry a meeting link, offline sessions carry a spot on campus.

4

Review each other

After a completed session both partners can leave one rating out of five, which builds each student's average score.

About this submission

Built for CSE311L

SkillSwap NSU is a Database Systems Lab project. The database is six normalised tables in MySQL with primary keys, foreign keys, unique constraints, CHECK constraints and indexes, driven by raw parameterised SQL — no ORM anywhere.

About this page: GitHub Pages can only serve static files, so this deployment reads the seeded rows from a JavaScript export of seed.sql. The same markup runs on Flask against MySQL for the final review, which is where the write operations live.
