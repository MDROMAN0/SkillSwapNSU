About this submission

Built for CSE311L

SkillSwap NSU is a Database Systems Lab project. The database is six normalised tables in MySQL with primary keys, foreign keys, unique constraints, CHECK constraints and indexes, driven by raw parameterised SQL — no ORM anywhere.

About this page: every number above was read from MySQL when the page loaded. Flask runs the queries, Jinja renders the result, and every button on the signed-in screens writes back to the same database.
